# 🎵 Spotify Clone

A Spotify-inspired music player UI built using **HTML, CSS, and JavaScript**. This project was created to practice frontend web development, responsive design, and interactive music player controls.

## ✨ Features

- ▶️ **Play & Pause** — Start and pause the currently selected song.
- ⏭️ **Next Song** — Skip to the next track in the playlist.
- ⏮️ **Previous Song** — Return to the previous track.
- 🎶 **Song Playlist** — Browse and play available songs.
- 📱 **Responsive Navigation** — Includes a slide-in menu for smaller screens.
- 🔊 **Volume Control** — Adjust the volume using a popup on mobile devices.
- 🎨 **Spotify-Inspired UI** — A familiar music player layout with a clean interface.
- 💻 **Interactive Controls** — JavaScript handles user interactions and playback functionality.

> **Note:** This is a practice project inspired by Spotify's interface. It is not affiliated with Spotify and does not connect to Spotify accounts or services.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and music player.
- **CSS3** — Handles styling, layout, animations, and responsive design.
- **JavaScript** — Implements playback controls, song navigation, and interactive UI elements.
